CITRUS — OFFLINE CONVERTER

DRAG TO CONVERT
1. Drag a file, then tap Shift.
2. Release Shift while still holding the mouse.
3. Move onto a named format wedge, then release the mouse.
4. Hold over More → for about 0.65 seconds to see another page.
   Move away before using More again. Do not drop on More.
The center and gaps are neutral. Escape cancels.

FILE PICKER
Double-click Citrus.exe.
Choose files… → Format / action → Convert.

Try Sample.jpg → PNG, WebP, AVIF, HEIC, PDF, resize or compress.
Select several images for Combine PDF, or several PDFs for Merge PDFs.
Try audio/video, documents, slides, spreadsheets, subtitles and archives.
For every file/folder: Copy path, Copy files, Show folder and Terminal.
Scanned PDF text needs OCR; PDF-to-Word is text-only reconstruction.

Closing with X keeps Citrus running in the tray.
Right-click the orange-and-leaf icon for Settings, Engine status,
Cancel all conversions, Open output folder, and Exit Citrus.
Start with Windows is already enabled.

Originals are preserved. Outputs are saved beside the source;
combined outputs are beside the first selected item.
New names are numbered instead of overwriting previous files.

Keep this folder and the project's .engines folder in place.
The app uses the configured local Python/FFmpeg/LibreOffice engines.
See README.md for the complete support matrix and known limits.
