I’m building Citrus — an open-source, offline file converter for Windows. 🍊

The idea is simple: drag a file, tap Shift, and drop it onto a format wheel beside your cursor.

Citrus stays in the system tray, processes files locally, and saves converted copies beside the originals. The current prototype supports conversions and tools across images, PDFs, documents, audio/video, subtitles and archives.

It’s an early preview. The local conversion and installer checks are passing, and I’m now working through fresh Windows testing and release packaging before making the installer publicly available.

I’d love feedback on the interaction, contributions, and help testing on fresh Windows systems.

Source and supported formats:
